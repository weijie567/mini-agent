# Legacy Runtime-first Design Archive

Archived on 2026-07-23.

These artifacts describe the earlier project direction in which a generic,
framework-free Mini Agent Runtime was the primary product and consumer order
and delivery support was only a reference application.

They were archived when the project was repositioned as a consumer-facing
order and delivery support Agent with a business-first implementation strategy.
None of these artifacts is evidence of implemented code.

## Contents

- `PROJECT_BRIEF.md`
- `PROJECT_OUTLINE.md`
- `DELIVERY_SUPPORT_SCENARIO_CONTRACT.md`
- `docs/architecture/`: previous architecture diagrams and exports
- `generated-analysis/graphify-out/`: reports, graph data, and query history

The files are retained for reference and can be restored by moving them back to
the project root. They are not active specifications for the new project.
