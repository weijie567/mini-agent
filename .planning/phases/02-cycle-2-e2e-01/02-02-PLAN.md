## Tasks

### Scoped encoding decisions

- `private_owner_scope` 与 `private_owner_scope_ref` 均编码为严格 opaque ref，保留
  Spec 的字段名；不得嵌入 raw `customer_id`。
- `ShipmentObservation.visibility` 固定为 `AUDIT_ONLY`；模型只消费
  `normalized_value` 的显式 projection。
- CandidateSet 只要求 `result_task_state_version > base_task_state_version`；不把现有
  `TaskStateTransition` 的 `+1` 偶然约束扩大为本 scoped contract。
- `record_schema_version` 是 candidate-set canonical payload 的固定常量/ClassVar；
  02-02 不发明 persistence envelope。
- current-set uniqueness、mapping closure、supersession 与 CAS 前置条件由 pure
  loaded-closure validator 表达；它们不是数据库原子性已实现的证据。
- 本 Packet 不扩展 Phase 1 `InputBinding(name="order_id")`。`product_description` /
  `candidate_ordinal` 的解析和 accepted-binding DTO 归 02-08；这里只保存 opaque
  `query_binding_refs` / `ordinal_input_binding_ref` 并验证 ordinal 参数。
