## Scoped encoding decisions

- Application 只声明持久化交互所需的 command/closure/result/Protocol；Core 已 reviewed
  的 record/DTO 直接 import。除 Application-owned `RunTaskLinkRecordV2` 外，不在
  `records.py` 重建五个逻辑记录或三个 Core-owned v2 parent 的字段。
- 为避免提前改变所有 Phase 1 Adapter，新增独立、显式 inactive 的
  `Cycle2RuntimeRecordPort`（或经 review 证明同等隔离的明确命名 Protocol）；不得向
  active `RuntimeRecordPort` 注入尚无实现的方法，也不得用 optional/dynamic probing
  兼容。
- Port 的 `APPLIED` 只表示 compliant Adapter 完成整个声明 aggregate 的 exact CAS
  与同事务写入；其他结果必须零写。Port declaration、read closure 或持久化 ref
  都不授予 Tool dispatch、业务事实或用户可见结果 authority。
- owner-scoped exact reader 返回 typed logical closure，不返回 raw envelope、SQL row、
  ORM entity、数据库 session 或 Adapter-private token。正常 absent 与 unauthorized
  不可区分；可见记录图出现矛盾时整体 fail closed。
- OA-10 使用独立 closed command 表达 exact obsolete Run suppression；因为 command
  不包含 Task/RequestUnit/result/message/response 字段，compliant Adapter 没有通过
  该 Port 修改它们的能力。`INCOMPLETE` 继续只属于 Phase 1 restart语义。
- 02-05 不激活 codec 或 physical version。02-06 拥有 exact codec/catalog，02-10
  拥有 migration/cutover，02-09 拥有 retry/recovery executor，02-11 拥有 PostgreSQL
  writer/readers，02-12 才拥有 active Runtime consumer。
