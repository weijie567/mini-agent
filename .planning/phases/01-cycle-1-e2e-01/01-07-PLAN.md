## Scripted provider boundary

`ScriptedModelProvider` implements the existing `ModelProvider` only. Construction binds one validated `model_script_ref`; calls consume only model-purpose steps in exact order and case completion requires cursor exhaustion.

- valid Request Understanding / Presentation steps construct existing canonical DTOs;
- Request Understanding invalid schema/source-authority/trusted-field attempts fail through canonical validation and never become authority;
- zero/multiple target-call protocol failures and invalid/fact-bearing Presentation envelopes discard raw input and raise a fresh parameterless `ProviderProtocolError` with `__cause__ is None` and `__context__ is None`;
- `script:fault-runtime:state-advanced-before-gate` returns a valid candidate with `base_task_state_version=None` and separately exposes one closed, one-shot `AFTER_REVALIDATION_BEFORE_GATE` directive to the injected SUT; Provider never mutates Task state;
- no retry, keyword routing, credential lookup, network access, arbitrary import/callback execution, `model_construct` or unchecked dict return is allowed.

## Qwen Responses Adapter boundary

`src/mini_agent/infrastructure/model/qwen_responses.py` implements the same existing `ModelProvider` with existing `httpx`; it adds no SDK, dependency, shared Port or DTO. Constructor injection supplies the base URL, API key and httpx client/transport so Component tests use `httpx.MockTransport` and make zero external network calls.

For each Request Understanding or Presentation purpose, the Adapter sends a closed top-level request projection containing only:

```text
model = "qwen3.7-plus-2026-05-26"
input = canonical purpose-specific model input projection
tools = exactly one current target function schema
tool_choice = that same target function
store = false
stream = false
```

No other top-level field, disabled field, trusted `customer_id`, raw private context, parallel tool set or unrelated function schema is sent. In particular:

- request body contains neither `previous_response_id` nor `conversation`;
- request headers contain no `x-dashscope-session-cache`;
- `tools` contains none of `web_search`, `web_extractor`, `code_interpreter`, `file_search` or `MCP`.

The response must contain exactly one call to the selected target function. Zero calls, multiple calls, wrong function, malformed arguments, invalid canonical output and lower-level raw failures discard the raw response/error before exposing a fresh parameterless `ProviderProtocolError` with no cause/context. The Adapter does not retry, stream, persist provider state or log credentials/raw payload.

`tests/component/model/test_qwen_responses_adapter.py` asserts the exact outbound JSON/header/tool denylist and authorization handling through MockTransport, plus zero/multiple/wrong/malformed call rejection and raw-error disposal. It never reads real credentials or performs real network I/O.

## Grader boundary

`graders.py` defines an Eval-local immutable evidence aggregate that references existing typed records, Core `TraceEvent` and safe observable scalars/counters. It must not redefine Message, Task, RequestUnit, ToolCall, Observation, ContextManifest, EvalResult or Failure records.

The registry contains exactly:

Unknown, duplicate or missing configured grader names fail execution. Every grader returns the existing `EvalGraderResult`; FAIL uses only existing stable reason codes. Any observed applicable Critical failure forces Case FAIL regardless of other scores.

The E2E01-04 comparator is a helper, not a fourteenth grader. It requires both A and B and compares only:

- `http_status`;
- `user_outcome`;
- `response_policy`;
- `ordinary_trace_shape`, normalized to ordered event type/count plus allowlisted stable status/reason only;
- `model_calls`.

It excludes IDs, customer/order values, raw payload and private facts.

## Harness boundary

`harness.py` defines local Protocol/callback seams rather than a shared Application Port:

```text
EvalCaseSut(case, scripted_provider, optional_fault_directive)
  → typed Eval evidence

append_eval_case_graded(canonical TraceEvent)
reload_trace(trace_ref)
EvalResultPort.append_eval_result(...)
EvalResultPort.append_eval_execution_failure(...)
```

Lane execution loads the entire selected set before persisting PASS/FAIL, so an incomplete E2E01-04 pair cannot leave a partial PASS. Per Case:

```text
preflight
  → injected SUT
  → all non-final-completeness graders
  → determine grader/CF outcome
  → append one canonical EvalCaseGraded through injected Trace callback
  → reload final Trace
  → TraceCompletenessGrader
  → construct existing EvalResultRecord
  → append through existing EvalResultPort
```

`PASS`/`FAIL` require outcome, trace reference and grader results. Critical failures require `FAIL`. `SKIPPED`/`NOT_RUN` carry no execution/grading/latency/usage data. For `qwen_baseline`, missing either required environment input or the 01-08 real EvalCaseSut creates the lane-defined empty NOT_RUN record; pytest may report SKIPPED only after asserting that record, and no 01-07 path performs network I/O. Unknown exact token counts mean `usage_summary=None`, not fabricated zero counts.

Failures before a complete valid Case result use the existing phase/error-code pair in `EvalExecutionFailureRecord`. Raw exceptions, Prompt, Token, credentials and customer/order PII are discarded. If primary Result persistence fails, attempt the safe Failure record path; if the result store is wholly unavailable, propagate a bounded command failure and never fabricate a Case result.

Duplicate `(eval_run_id, case_id, attempt)` is append-only: exact existing replay may be returned only after loading and comparing the complete record; a conflicting duplicate is a result-persistence failure and never overwrites history.
